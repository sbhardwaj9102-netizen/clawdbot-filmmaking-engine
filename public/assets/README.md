# Assets

All files in these folders are **placeholders** generated by `scripts/placeholders/generate.py`.
Replace any file with a real still or clip **using the same file name** and the site picks it up —
in the 3D worlds, Quick Mode, the lightbox and the `/work` pages. No code changes required.

Paths are referenced from `src/data/projects/*.ts`, `src/data/worlds/events.ts` and `src/data/profile.ts`.
The 3D worlds use downsized copies in `public/tex/`, rebuilt automatically by
`scripts/optimize-textures.mjs` before every `dev` / `build`.

| Folder | Used by |
| --- | --- |
| `site/` | The reel (`hero.mp4` + `hero.jpg` poster) on the film-set screen and the camera's WATCH; the About-screen portrait; film grain |
| `aster/` | ASTER's world: production slate, location map + prints, stripboard, crew briefing, BTS wire, wall of frames |
| `purple/` | DEATH AT THE HOUSE OF PURPLE: four set rooms (`set-0x`), the fire sequence (`fire-01`, `safety`, `execution`), `planning`, `construction`, BTS |
| `rana/` | RANA: `poster`, `still-0x`, monitor `cover` |
| `gluttony/` | GLUTTONY: `poster`, `still-0x`, monitor `cover` |
| `events/` | The events venue: pillars (`vendors`, `clients`, `venue-setup`, `timelines`, `logistics`, `live`), LED wall (`cover`), gallery |

Suggested sizes — wide: 2000×1125 (covers 2400×1350) · tall: 1200×1500 · frames: 2000×840 (2.39:1).
When every placeholder is replaced, set `assetsArePlaceholders: false` in `src/data/profile.ts`.
