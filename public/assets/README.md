# Assets

All files in these folders are **illustrations** generated by `scripts/placeholders/generate.py`,
standing in for production stills. Replace any file with a real still or clip **using the same
file name** and the site picks it up — on set in the 3D rooms, in the tour's image reveals,
Explore's galleries, Quick view, the lightbox and the `/work` pages. No code changes required.

Paths are referenced from `src/data/projects/*.ts`, `src/data/worlds/events.ts`,
`src/data/profile.ts` and `src/data/story.ts`. The 3D rooms use downsized copies in
`public/tex/`, rebuilt automatically by `scripts/optimize-textures.mjs` before every `dev` / `build`.

| Folder | Used by |
| --- | --- |
| `site/` | The projection screen in the producer's room (`hero.jpg`), the About fallback (`portrait.jpg`), film grain |
| `aster/` | The ASTER wall (cover, location prints), the tour's ASTER beat, Explore → Work → ASTER, the `/work/aster` page |
| `purple/` | The House of Purple beat and gallery: sets, the fire sequence, planning, construction, BTS |
| `rana/`, `gluttony/` | The film monitors cart, Explore → Work → RANA · GLUTTONY, their `/work` pages |
| `events/` | The live-events beat, the projection screen during it, Explore → Work → Live events |

Suggested sizes — wide: 2000×1125 (covers 2400×1350) · tall: 1200×1500 · frames: 2000×840 (2.39:1).
When every illustration is replaced, set `assetsArePlaceholders: false` in `src/data/profile.ts`.
