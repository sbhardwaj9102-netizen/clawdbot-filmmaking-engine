# Assets

All files in these folders are **placeholders** generated by `scripts/placeholders/generate.py`.
Replace any file with a real still or clip **using the same file name** and the site picks it up —
no code changes required. Paths are referenced from `data/projects.ts` and `data/site.ts`.

| Folder | Used by |
| --- | --- |
| `site/` | Opening shot (`hero.mp4` + `hero.jpg` poster), About portrait, film grain texture |
| `aster/` | ASTER card + case study (`cover`, chapters, `bts-0x` gallery, `frame-0x` sequence) |
| `purple/` | DEATH AT THE HOUSE OF PURPLE (`cover`, timeline: `planning` → `construction` → `safety` → `execution`, `set-0x`, `fire-01`, `bts-0x`) |
| `rana/` | RANA (`cover` wide, `poster` tall card, `still-0x`) |
| `gluttony/` | GLUTTONY (`cover` wide, `poster` tall card, `still-0x`) |
| `events/` | Event Operations (pillars, `venue-empty` / `venue-setup` / `venue-live` transformation, gallery) |

Suggested sizes — wide: 2000×1125 (covers 2400×1350) · tall: 1200×1500 · sequence frames: 2000×840 (2.39:1).
For the venue transformation, shoot all three states from the **same locked-off camera position** so the wipe lines up.
